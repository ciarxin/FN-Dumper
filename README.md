# What is this ❓
This is an internal dumper for Fortnite Version 14.40 ( Retrac )

# Is This Undetected? 🤞
The short answer is no. This dumper doesn't utilize any evading measures to keep it from being noticed by the anti-cheat.

# Could I use this on other Unreal Engine games? 🤷‍♂️
Yes, you may need to tweak the scanner and the class names for the offsets for it to work on other Unreal Engine games, as for now it is meant for fortnite.

# How do I make it dump different offsets? 👀
You need to call the FindOffset function and pass the class the offset is in, and the member name.
